# Production Checklist

قبل استخدام بيانات المدرسة الحقيقية:

- [ ] تشغيل `setupSystem()` على Google Sheet مخصص للإنتاج.
- [ ] حذف/تغيير `BOOTSTRAP_ADMIN_PASSWORD` من Script Properties بعد أول Setup (الدالة تحذفه تلقائياً).
- [ ] نشر Apps Script كـ Web App جديد وحفظ Deployment URL.
- [ ] تجربة Login للـAdmin ثم إنشاء حسابات الموظفين المطلوبة فقط.
- [ ] إضافة الموظفين والمعلمين وتثبيت Teacher Codes.
- [ ] تعيين PIN جديد لكل معلم يحتاج Teacher Portal.
- [ ] إضافة الطلاب والفصول ومراجعة الأكواد.
- [ ] ضبط العام/الترم وتاريخ Week A في إعدادات الجدول.
- [ ] مراجعة أوقات الحصص والفسح.
- [ ] استيراد الجدول كـ Draft ثم فحص التعارضات ومطابقة 39 حصة A/B.
- [ ] مراجعة Teacher Load وعدم وجود Overload غير مقصود.
- [ ] اختبار الاحتياطي: 29/30 ثم 30/30 ثم رفض 31/30.
- [ ] اختبار تعارض الحصة/الاحتياطي/الإشراف/الإجازة/عدم الإتاحة.
- [ ] نشر بعض Schedule Items والواجبات والامتحانات فقط للتجربة.
- [ ] اختبار Teacher Portal بحساب معلم محدود.
- [ ] إنشاء Student Token تجريبي والتأكد أن الطالب لا يرى أي بيانات إدارية.
- [ ] مراجعة Audit Log.
- [ ] تفعيل GitHub Pages عبر GitHub Actions.
- [ ] أخذ نسخة من Google Sheet قبل التشغيل الفعلي.
